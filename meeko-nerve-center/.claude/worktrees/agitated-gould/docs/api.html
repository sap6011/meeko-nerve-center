Infrastructure API

SolarPunk is infrastructure. Infrastructure charges fees. Not charity — value exchange. Workers always free. Orgs pay their way.

"Any organization using our labor marketplace, crisis routing, or AI capabilities pays a micro-fee. That fee goes directly to worker wages and crisis routing. Using SolarPunk = funding it."
Workers Always Free
No ID. No bank. No experience required. Plant a tree, label data, verify work — get paid. Zero fees for the people who need it most. The orgs generating demand pay the fees that fund the workers.
API Endpoints
POST /api/v1/crisis/route 0.001 USD per call — goes 100% to crisis pool
Route funds to crisis organizations (PCRF, IRC, MSF, UNICEF)

Auth: Bearer token (free registration)
Rate limit: 1000 calls/day free tier
POST /api/v1/labor/post 10 USD per task posting
Post task to SolarPunk labor marketplace
Workers earning from tasks always free — fee only for task posters
GET /api/v1/proof/bundle FREE
Get current impact proof bundle
SHA256-verified bundle of all impact events
POST /api/v1/verify/worker FREE
Verify a worker's task completion
POST /api/v1/print/dispatch FREE
Dispatch 3D printed part to crisis region
Crisis zones only, verified need required
