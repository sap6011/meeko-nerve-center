Got 5 minutes?
Help SolarPunk. Get credited.

Every task below becomes a timestamped GitHub Issue — permanent proof of contribution, attached to your GitHub account, visible forever in the repo history.

How it works

  1. Click Start Task on any card below
  2. A pre-filled GitHub Issue opens in a new tab
  3. Fill in what you found / did, then submit the Issue
  4. Your name + timestamp = permanent credit on the repo

No special access needed. Any GitHub account works. The Issue is your receipt — timestamped, immutable, public. If a task leads to a grant award, you may be eligible for the 20% finder's fee logged in the Issue.

Share SolarPunk

~5 min

Post the repo or the site to one community you're part of — Mastodon, Reddit, a Discord, a newsletter, anywhere. Paste the link you posted in the Issue. That's it. Signal is infrastructure.
