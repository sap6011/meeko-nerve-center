Under the Hood

How the Blob Brain Works

Every 5 seconds, one function runs 158 neuron functions in sequence. Each neuron reads from a shared Python dictionary called CONSCIOUSNESS, processes something, and writes back. At the end of the cycle, the entire dictionary is written to one file: blob_brain.json.

NEURONS = [
  ("EQUILIBRIUM", neuron_equilibrium),
  ("RISK_RADAR", neuron_risk_radar),
  ("SWARM_CONSENSUS", neuron_swarm_consensus),
  ("GRAND_UNIFIED", neuron_grand_unified),
  # ... 154 more
]

Neuron types:

  • Absorbers — Pull data from files, APIs, and external sources into consciousness
  • Intelligence — Analyze, correlate, predict, and detect patterns
  • Synthesis — Combine all signals into unified assessments
  • Action — Execute decisions, publish content, trigger workflows
  • Meta — Observe the observer. Track the brain tracking itself.
