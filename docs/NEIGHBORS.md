## The Flock Strategy

SolarPunk isn't trying to be the only node. The goal is a network where each node does what it's best at:
- **We** do grant discovery, transparency logging, revenue routing, security murmuration
- **solarpunk_utopia** does offline-first mesh networking for communes
- **Permastead** does physical-earth tracking for permaculture
- **arwes** does the visual identity layer

When these nodes can read each other's vital signs (see: VITAL_SIGN_API), the flock murmuration extends beyond a single repo. That's the endgame.
